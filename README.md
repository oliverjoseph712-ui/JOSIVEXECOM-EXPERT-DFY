# Josivex Expert — Done-For-You E-commerce Services

A single-file static site (`index.html`). No build step, no dependencies.
This is a **separate site** from the Josivex Expert mentorship site, it should live in its own GitHub repo and its own Vercel project (so it gets its own URL).

## Deploy on Vercel

1. Push this folder to its own new GitHub repo.
2. On https://vercel.com → **Add New Project** → import that repo.
3. Framework preset: **Other**. Leave Build Command and Output Directory blank.
4. Click **Deploy**.

## What's real vs. placeholder on this site

Per the brief, every dashboard screenshot and the video in the "Results" marquee are genuine assets you supplied, nothing there is invented.

The following sections are intentionally built as clearly-labeled placeholders, since no real assets were supplied for them yet. Swap them out whenever you have the real material:
- **Work We've Actually Done** (portfolio grid): six category tiles, each reading "Add [x] project here."
- **What Clients Say** (chat/review cards): reads "Add a real client message or review here."
- **Creative Showcase**: six "Watch Creative" tiles with no real video attached yet.

Nothing fabricated: no invented client names, revenue figures, testimonials, or results, in line with the Authenticity Rule in the original brief.
